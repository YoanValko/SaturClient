Building Satur Client

The project targets Minecraft 1.21.11 and Java 21.

Prerequisites

  • JDK 21 with java and javac available.
  • A disposable VM or isolated test machine.
  • Enough disk space for Gradle and Fabric dependencies.

See the Fabric developer guides for general development concepts.

Build from source

  1. Extract Satur-client-source.zip into a disposable working directory.
  2. Open a terminal there.
  3. Confirm Java 21:
java -version
javac -version

Then build:

.\gradlew.bat build

If successful, the output is under build\libs\ and begins with satur-client-. The first build may download Gradle and third-party dependencies, so do not run it on your everyday Windows installation.

Run the development client

.\run.bat

This has not been validated in the safety review. Modules that depended on the removed injector may need compatibility adapters.

Install a compiled JAR

Only after reviewing the build output, copy the resulting JAR into the mods folder for the matching Fabric profile. No compiled JAR is distributed by this site.
