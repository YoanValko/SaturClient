ALPHA NOTES

Saturn Client Alpha

A reviewed build candidate for Minecraft 1.21.11 Fabric.

What changed

The supplied Kuro source was rebranded to Saturn Client Alpha. The mod ID, entrypoint, resource namespace, config namespace, logger names, and archive name now use Saturn. The internal dev.kuro package namespace remains to reduce compatibility risk, and that provenance is documented rather than hidden.

Build evidence

  • gradle build --no-daemon completed successfully with Java 21.
  • gradle runClient --no-daemon loaded saturn 1.0.0-alpha and reached the render/resource stage.
  • A stale resource-namespace issue found during the first smoke run was corrected and rebuilt.

Security scope

Static review found no process spawning, raw network clients, webhooks, browser/token access, native loading, persistence, or self-delete patterns. The code still uses normal Minecraft/Fabric networking, local config/profile writes, clipboard features, reflection for its event bus, and external build dependencies. This evidence is not a guarantee of safety.

Safe testing

Verify the JAR hash, use Windows Sandbox or another disposable profile, keep networking disabled while inspecting, and never sign in or provide Microsoft, Minecraft, browser, Discord, or other personal credentials.
