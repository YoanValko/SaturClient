ALPHA NOTES

Saturn Client Alpha

The first Saturn Client build for Minecraft 1.21.11 Fabric.

What changed

The supplied source was rebranded to Saturn Client Alpha. The mod ID, entrypoint, resource namespace, config namespace, logger names, and archive name now use Saturn. The internal dev.kuro package namespace remains to reduce compatibility risk.

Build details

  • gradle build --no-daemon completed successfully with Java 21.
  • gradle runClient --no-daemon loaded saturn 1.0.0-alpha and reached the render/resource stage.
  • The native Saturn menu and local module bridge are included.

Getting started

Install Java 21, use the supplied Gradle wrapper, and launch the client with a separate Minecraft profile. The repository includes Windows Sandbox profiles and build instructions.
