Getting started

This guide covers Minecraft Java Edition, Fabric, and isolated testing.

Install Minecraft Java Edition

Download the official Minecraft Launcher from Minecraft.net or the Microsoft Store. Sign in only in your normal Minecraft profile; do not sign in inside Windows Sandbox.

Satur Client targets Minecraft Java Edition 1.21.11. Create and launch that exact version once before installing Fabric.

Install Fabric

  1. Follow the official Fabric Windows installation guide.
  2. Download the Windows Fabric Installer.
  3. Close Minecraft and the launcher.
  4. Select Minecraft 1.21.11, keep Create Profile enabled, and install.
  5. Open the launcher, select Fabric, and launch once.

Use the supplied sandbox

Use Satur-strict.wsb for source inspection. It disables networking and host-folder mapping. To bring in the ZIP, use Satur-readonly-input.wsb and create C:\SaturClientSandbox\incoming on the host. The folder appears inside the sandbox as C:\Incoming and is read-only.

Safety rules

  • Do not use your normal .minecraft directory.
  • Do not copy Microsoft, Minecraft, browser, or Discord tokens into the sandbox.
  • Keep networking disabled while inspecting or running the client.
  • Close Windows Sandbox when finished; its contents are deleted.
  • Treat future updates and third-party dependencies as untrusted until reviewed.

The download contains source and documentation, not a verified compiled JAR.
