BUILD GUIDE

Building Saturn Client Alpha

The Alpha targets Minecraft 1.21.11, Fabric Loader 0.20.1, and Java 21.

Build from source

  1. Extract Saturn-client-alpha-source.zip into a disposable working directory.
  2. Install JDK 21 and confirm with java -version.
  3. Keep networking disabled while inspecting or testing.
gradle build --no-daemon

The remapped output is build\libs\saturn-client-alpha-1.0.0-alpha.jar. A first build may download Gradle and Fabric dependencies, so use Windows Sandbox, a VM, or another disposable profile.

Smoke test

gradle runClient --no-daemon

The reviewed run loaded saturn 1.0.0-alpha and reached Minecraft’s render/resource stage. Shader sampler and development refmap warnings are documented in the Alpha review.

Install

Verify the published JAR hash before copying it into a Fabric 1.21.11 profile. Do not use your normal .minecraft directory or real account credentials.
