Satur Client FAQ

What is Satur Client?

Satur Client is an experimental Minecraft client focused on customization, UI, and modular gameplay features.

Does it include the existing interface?

It reuses the project interface and module presentation while adding a local API and compatibility layer.

Are all modules guaranteed to work?

No. Compatibility depends on the Minecraft and Fabric versions, and some modules may still need individual fixes.

Is it guaranteed safe?

No. Static review and source inspection can reduce risk but cannot prove that arbitrary future builds are safe. Use the verification guide and a disposable environment.

Why is there no compiled JAR?

The project distributes reviewed source rather than presenting an unverified compiled binary as trusted.
