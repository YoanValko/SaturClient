Satur Client FAQ

What is Satur Client?

Satur Client is a hardened source copy with a local custom API and the original injector, native loader, remote loaders, self-destruct behavior, and several developer hooks removed.

Does it have the same GUI?

It reuses the existing GUI layout and module manifest. The Beta now uses a local Java/Minecraft-rendered menu with Satur branding and a procedural black-hole mark.

Are all modules guaranteed to work?

No. The custom API preserves compatibility signatures, but modules that depended on removed hooks may need individual fixes.

Is it guaranteed malware-free?

No static review can prove that. Known high-risk paths were removed, but dependencies and reflection still require caution.

How do I verify it?

Compare the published SHA-256 hash, inspect the source, and test only in an isolated disposable environment without real credentials.
