DEFENSIVE VERIFICATION

Tools for reviewing the source

These tools help find suspicious behavior; they cannot prove that an unknown client is completely safe. Keep testing isolated and offline.

Recommended toolkit

  • Windows Sandbox: disposable execution environment. Use the supplied strict profile with networking and host-folder mapping disabled.
  • Microsoft Defender: update signatures, then run a custom scan over the ZIP and extracted folder.
  • Process Monitor: observe file, Registry, process, and thread activity while testing.
  • TCPView: inspect unexpected connections and listening ports. Run only inside an isolated test environment.
  • JDK tools: use jar, jdeps, and javap to inventory classes, dependencies, and bytecode.
  • Gradle dependency reports: inspect direct and transitive libraries before building.
  • Git and SHA-256: verify that the downloaded archive matches the published checksum before extracting it.
  • Optional static scanners: Semgrep, SpotBugs, and OWASP Dependency-Check can add coverage, but their clean results are not a safety guarantee.
  • Included source check: run tools\verify-safe.ps1 after changes; it fails on process, native-loader, raw-network, credential, or self-destruct patterns and reports reflection/filesystem items for review.
  • GUI note: the Beta uses a local Java/Minecraft-rendered menu; the old ImGui Java/native backend has been removed from the build.

Safe order of operations

  1. On the host, calculate the archive hash. Do not execute it.
  2. Scan the ZIP with Defender and inspect the source as text.
  3. Extract it into the disposable sandbox, never into your normal Minecraft folder.
  4. Run the source build with networking disabled. Do not sign in or copy browser, Discord, Microsoft, or Minecraft tokens.
  5. Use Process Monitor and TCPView only if you deliberately perform a runtime test. Save logs for review.
  6. Close Windows Sandbox when finished so its temporary contents are discarded.

Useful commands

Get-FileHash .\Satur-client-source.zip -Algorithm SHA256
Start-MpScan -ScanType CustomScan -ScanPath .\Satur-client-source.zip
Get-MpThreatDetection

jar tf .\build\libs\*.jar
jdeps --multi-release 21 --recursive .\build\libs\*.jar
.\gradlew.bat dependencies
.\gradlew.bat dependencyInsight --dependency <name>

Run Defender commands in an elevated PowerShell window if Windows requests it. Never create antivirus exclusions for this project.

What to treat as a stop sign

  • Runtime.exec, ProcessBuilder, PowerShell, CMD, or shell-script launches without a clear build reason.
  • Network clients, webhooks, Discord bots, remote class/JAR loading, native libraries, or obfuscated reflection.
  • Reads of browser profiles, cookies, tokens, wallets, SSH keys, Discord data, or unrelated directories.
  • Self-delete, persistence, startup tasks, Registry autoruns, hidden windows, or attempts to disable Defender.
  • Unexpected outbound connections during an offline test.

Important: A VPN, antivirus result, clean hash, or successful compilation does not make the client safe. Do not run it on your main Windows installation.
