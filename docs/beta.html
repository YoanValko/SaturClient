What changed

  • The old ImGui binding, OpenGL GUI backend, and bundled native GUI libraries were removed.
  • The menu now uses Minecraft's native Java screen renderer and keeps module toggles local.
  • The menu layout is ported from the supplied design: category sidebar, module cards, enabled-state styling, and scroll support.
  • The module/settings compatibility bridge remains local and typed.

Module compatibility

GUI implementation is a work in progress. Some module settings may be missing, and keybind support is still being developed. Use Alpha for the best current integration while the Beta bridge continues to evolve.
